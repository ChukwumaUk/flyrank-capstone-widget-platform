# Embeddable Widget & Lead-Capture Platform

A platform for creating embeddable lead-capture widgets, delivering them via a one-line
`<script>` snippet, and safely accepting submissions from the public internet —
validated, rate-limited, spam-filtered, geo-enriched, and dashboarded.
